## 清晰的主线

**方向匹配 → 功率分配 → 测量可信 → 扰动后可靠 → 系统用途。**

每轮先写问题，再决定方法。RCWA 谐波数、FDTD 网格与 PML 是数值精度问题；周期、齿高和齿宽是结构问题；光斑和角度是输入条件；它们不能混成一次无约束“优化”。

## 下一阶段计划

先完成六次 60–90 分钟的主动学习：光路与坐标、功率定义、手算相位匹配、只读源检查、回放高度三点实验、设计波长验证。预计 6–9 小时不包含求解等待，也不是整机设计工期。

工程上先审计导入源与模式分类、复现名义点，再规划有限范围的波长、角度、位置、光斑与制造扰动。模型改变后，针对性检查数值收敛；不要重新无限扫描。之后再学习扩瞳、眼盒、RGB、鬼影与成像系统。
