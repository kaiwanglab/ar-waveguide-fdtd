## 二、已经学习的物理知识

### 1. 全反射与临界角

光从高折射率介质射向低折射率介质时，临界角为：

\[
\theta_c=\arcsin\left(\frac{n_2}{n_1}\right)
\]

以波导折射率 1.8、空气折射率 1.0 为例：

\[
\theta_c=\arcsin(1/1.8)\approx33.75^\circ
\]

波导内部传播角大于临界角时才可能发生全反射。AR 波导设计不能只追求“光进入波导”，还必须检查进入后的角度是否满足全反射传播条件。

### 2. 光栅方程与衍射级次

一种常用写法为：

\[
n_{out}\sin\theta_{out}=n_{in}\sin\theta_{in}+m\frac{\lambda}{\Lambda}
\]

- \(m\)：衍射级次，常见为 0、+1、-1。
- \(\lambda\)：波长。
- \(\Lambda\)：光栅周期。
- 正负号取决于坐标轴、光栅矢量方向和软件的级次定义。

必须记住：

- `+1` 和 `-1` 没有脱离坐标系的固定物理含义。
- AR 入耦器应选择“把光送入目标波导传播方向”的那个一级衍射级次。
- 0 级通常接近镜面透射/反射，没有提供所需的额外横向动量，所以一般不能完成波导相位匹配。
- 判断级次不能只看名字，要结合 k 向量方向、场传播方向和输出角。

### 3. 相位匹配

入射光的面内波矢与光栅提供的动量之和，需要匹配波导模式传播常数：

\[
\beta=k_0 n_{eff}=k_{x,in}+mG
\]

其中：

\[
G=\frac{2\pi}{\Lambda}
\]

因此周期、入射角、波长和有效折射率共同决定相位匹配峰值。优化周期的本质不是“寻找一个更大的数字”，而是在寻找满足动量匹配的位置。

### 4. TE 与 TM

- TE/TM 是相对于传播平面定义的偏振。
- 在二维模型中，软件里的 polarization angle 必须结合实际仿真平面判断，不能机械记忆 0° 或 90°。
- 当前修正后的二维 FDTD 模型使用 x-y 平面：x 为光栅/传播方向，y 为垂直厚度方向，z 为不变量方向。
- 当前模型中使用 polarization angle=90° 表示所验证的 TM 情况。

### 5. 占空比、齿宽和间隙

\[
duty=\frac{width}{period}
\]

\[
width=duty\times period
\]

\[
gap=period-width
\]

占空比改变会同时改变高折射率区和低折射率区的宽度，从而改变等效折射率、傅里叶谐波强度、相位和衍射效率。最佳值通常不是 50%，也不能假定扫描区间的边界就是最佳值。

### 6. 输出角计算

使用光栅方程求输出角：

\[
\theta_{out}=\arcsin\left(\frac{n_{in}\sin\theta_{in}+m\lambda/\Lambda}{n_{out}}\right)
\]

计算后还要检查：

1. `asin` 的输入是否在 [-1,1]。
2. 角度是否满足波导全反射。
3. 正负方向是否与目标传播方向一致。
4. 波长变化时输出角漂移是否会造成彩虹纹或 RGB 不重合。

## 三、已经掌握的 Lumerical 操作与结果读取

### 1. 基本对象

你已经接触并实际建立/使用：

- FDTD simulation region
- RCWA solver
- Plane Wave source
- Gaussian source
- Frequency-domain field/power monitor
- Mode expansion monitor
- Mesh override
- 波导芯层、光栅齿和材料结构

### 2. Layout 与 Analysis

- Layout：修改结构、光源、监视器和网格。
- Analysis：仿真完成后的结果状态。
- 修改结构前通常要 `switchtolayout;`。
- `run;` 才真正启动求解；只在 Script Prompt 定义变量或设置参数不会自动完成仿真，除非脚本中包含 `run;`。

### 3. Apply 与 OK

- Apply：应用设置但保持窗口打开，便于检查。
- OK：应用设置并关闭窗口。
- 通常可以直接点 OK；教学阶段先 Apply 是为了看到模型是否按预期变化。

### 4. Script Prompt、脚本和 `feval`

- Script Prompt：执行单行或短命令。
- `.lsf`：保存可重复执行的脚本。
- `feval("路径/脚本.lsf");`：执行指定脚本文件。
- `setnamed`：按对象名设置参数。
- `getnamed`：读取对象参数。
- `getresult`：读取结果数据集。
- `pinch`：去掉长度为 1 的多余维度，便于索引和计算。
- `transmission`：读取功率监视器的归一化透射结果。
- `integrate`：对线/面上的数据积分，但必须明确数组维度和积分坐标，不能看到矩阵就随意积分。

### 5. RCWA 结果应该看什么

- `grating orders`：查看各衍射级次、角度/方向及对应数组。
- `grating power`：查看归一化到各级次的功率分配。
- 目标是读取目标方向的一级衍射效率，而不是只看总 Transmission。
- 数组索引不是衍射级次本身；必须使用 `n`/级次列表找到 `m=+1` 对应的索引。

### 6. FDTD 结果应该看什么

- `power_right/left/top`：穿过监视器的总净 Poynting 功率。
- `mode_right` 的 `T_forward/T_backward`：与所选波导本征模匹配的前向/后向功率。
- 总功率不等于目标导模功率。
- 模式展开结果存在名称不等于 Calculate 一定成功。
- 场图应检查能量到底在自由空间、光栅附近还是波导芯层中传播。

### 7. Visualizer

- `Magnitude` 通常是场幅值，不等于 \(|E|^2\)。
- \(|E|^2=|E_x|^2+|E_y|^2+|E_z|^2\)。
- 横轴可通过 Parameters 中 Axis min/max、缩放工具或脚本绘图范围调整。
- 曲线难以人工读数时，应输出 CSV/结果卡，而不是用肉眼猜像素。

## 四、RCWA 阶段已完成的内容

### 1. 为什么先用 RCWA

RCWA 适合周期结构：

- 单周期计算速度快。
- 适合扫周期、占空比、齿高、角度、波长和偏振。
- 能直接分解衍射级次。
- 适合做粗筛、精扫和制造公差。

但 RCWA 的周期边界代表无限重复结构，不能独立证明有限长度入耦器的真实总入耦效率。

### 2. 已进行的扫描

- 周期扫描与细扫。
- 占空比/齿宽扫描。
- 齿高扫描。
- 入射角粗扫与细扫。
- TE/TM 双偏振比较。
- k vectors 收敛检查。
- ±5 nm 齿宽/齿高制造公差 3×3 扫描。
- 波长容差和输出角漂移。

### 3. RCWA 工程候选

曾形成的工程候选包括：

- 波长 638 nm
- 周期约 407 nm
- 入射角约 -13°
- 齿宽约 210 nm
- 齿高约 175 nm
- 双偏振指标采用 `min(TM+1, TE+1)`，偏振差采用 `abs(TM+1-TE+1)`

这个候选代表 RCWA 周期单元阶段的设计中心，不能与后续有限 FDTD 的临时候选直接混为同一个“最终结构”。

### 4. k vectors 的物理与数值意义

RCWA 把介电常数和电磁场展开为傅里叶谐波。k vectors 越多：

- 能表达更尖锐的材料边界和更高空间频率。
- 通常更准确，但计算更慢、内存更多。
- 目标不是无限增加，而是让目标效率随 k 数基本不变。

建议用相邻两档的目标效率变化判断，例如相对变化 <1% 作为常用工程标准。

## 六、最重要的阶段性发现：优化结果尚未通过验证

### 1. 原平面波问题

斜入射无限平面波会直接穿过侧面的模式展开截面，使 `mode_right` 同时看到：

- 真实波导导模。
- 未耦合的入射背景。
- 光栅散射辐射。
- 近场和倏逝场。

因此模式展开系数会随监视器位置强烈变化。

### 2. 背景复振幅扣除

使用有光栅与无光栅参考，尝试按复振幅扣除背景。结果：

| 监视器间距 | 扣背景后 TM 前向 |
|---:|---:|
| 800 nm | 0.00478507% |
| 1000 nm | 0.045632% |
| 1200 nm | 0.0343783% |

相对离散度 144.514%，验证失败。

说明简单的无光栅背景扣除仍不足以分离散射场与导模。

### 3. Gaussian 源验证

将无限平面波替换成有限 Gaussian 光束：

- x=0，x span=9 µm
- y=0.75 µm
- y-axis，Backward
- angle=-12.5°
- TM=90°
- w0=2.5 µm
- distance from waist=-0.75 µm

1000 nm 基准：

- TM forward：0.0182883%
- TM backward：0.0000487968%
- right total：1.80204%
- left total：0.464786%
- top total：74.2768%

Gaussian 三位置验证：

| 监视器间距 | TM forward | TM backward | right total |
|---:|---:|---:|---:|
| 800 nm | 0.0239297% | 0.000139668% | 1.66062% |
| 1000 nm | 0.0182883% | 0.0000487968% | 1.80204% |
| 1200 nm | 0.00852685% | 0.000160922% | 1.72182% |

相对离散度从 144.514% 降到 91.0606%，有所改善，但仍未达到 ≤10% 的初步收敛要求。

### 4. 你现在应该形成的判断习惯

看到最高效率时，不应立即说“优化成功”，而要依次问：

1. 目标级次/模式选对了吗？
2. 归一化分母是什么？
3. 能量监视器是否形成合理闭合？
4. 监视器换位置结果是否稳定？
5. 网格变化后结果是否稳定？
6. 仿真区域和 PML 距离够吗？
7. 源是否直接照到结果监视器？
8. 场图是否真的显示能量被束缚在波导芯层？

## 七、为什么最近感觉学得慢

主要不是理解能力问题，而是学习路径中出现了三个效率损失：

1. 在结果可信度尚未建立前进行了很多轮结构扫参。
2. 一些操作由脚本快速完成，但“参数为什么这样设”没有在每轮前先讲清。
3. GUI、脚本、物理和数值验证四条线同时推进，认知负担太高。

后续调整为：每节课只解决一个可验收问题；每次运行前先写出输入、输出和判据；每轮最多改变一个变量组。

## 八、接下来学习框架

### 阶段 A：把当前 FDTD 结果测准

目标：获得与监视器位置、网格和边界无关的可信 TM 导模效率。

内容：

- 扩大公共仿真区域。
- 远距离模式监视器收敛。
- Gaussian 光束路径与监视器空间分离。
- 模态剖面、n_eff 和模式选择复核。
- 完整功率账本与符号方向。
- 必要时改为端口/散射场分离方法。

验收标准：

- 2/3/4 µm 三个监视器位置的 TM forward 相对离散度 ≤10%，理想 ≤5%。
- 5 nm 与更细局部网格的目标效率变化 ≤5%。
- 场图显示波导芯层内存在连续传播的目标模式。
- 解释清楚总右向功率与目标 TM 模态功率的区别。

### 阶段 B：重新验证结构优化

目标：在可信测量方法下重做最少量的局部优化。

内容：

- 以 RCWA 候选为中心，先周期/角度二维小范围扫描。
- 再扫占空比/齿高。
- 最后扫齿数或 Gaussian 光斑位置。
- 采用效率、方向性、偏振差和容差的多目标指标。

验收标准：

- 每个候选都使用相同归一化和监视器位置。
- 最优点不是扫描边界；若在边界则扩展范围。
- 给出局部响应曲面，而不只报告一个最大值。

### 阶段 C：从单个入耦器走向 AR 波导功能

目标：理解入耦—全反射传播—出耦的完整链路。

内容：

- 入耦器、扩瞳器和出耦器各自功能。
- 传播角与 TIR 条件。
- 单向性与寄生级次。
- 出瞳位置、眼盒和均匀性。
- 一维扩瞳与二维扩瞳差异。

验收标准：

- 能画出 k-space/光路示意并说明各光栅矢量作用。
- 能从目标 FOV 和折射率反推允许的内部传播角范围。

### 阶段 D：彩色与视场

目标：从单波长 638 nm 扩展到 RGB 和角度范围。

内容：

- 460/532/638 nm 或实际显示光机波长。
- 波长色散和输出角漂移。
- RGB 共视场与重合。
- 彩虹纹、零级漏光和杂散级次。
- TE/TM 偏振敏感性。

验收标准：

- 输出 wavelength-angle map。
- 标出可传播、TIR、不可传播和寄生区域。
- 能解释为什么单波长高效率不等于彩色 AR 可用。

### 阶段 E：系统指标与工程验证

目标：建立 AR 行业真正关心的指标体系。

内容：

- FOV、eyebox、eye relief。
- 亮度效率和均匀性。
- MTF/分辨率、畸变、色差。
- stray light、ghost、rainbow。
- 制造公差、材料色散、表面倾斜和厚度误差。
- RCWA/FDTD 结果向 Zemax 或系统模型传递。

验收标准：

- 完成一份入耦结构技术报告。
- 给出名义性能、网格收敛、角度/波长容差和制造公差。
- 清楚区分局部衍射效率、波导传输效率与整机眼盒效率。

## 九、建议的 6 周学习计划

建议每周 3 次，每次 1.5～2 小时，总计约 30～36 小时。

交付物：一张收敛表、一张场图、一份功率账本。

### 第 2 周：可信条件下的局部优化

- 第 1 次：周期与角度小范围二维扫描。
- 第 2 次：占空比与齿高小范围二维扫描。
- 第 3 次：复查最优点、方向性和场分布。

### 第 3 周：偏振、波长和制造容差

### 第 4 周：入耦—传播—出耦链路

## 十、以后每次学习固定流程

每节课只走以下七步：

1. **今天的问题**：一句话写清要解决什么。
2. **固定参数**：列出本轮绝对不变的参数。
3. **唯一变量**：明确只改什么。
4. **预测**：运行前先说结果可能如何变化以及原因。
5. **运行**：保存 before-run 副本后再运行。
