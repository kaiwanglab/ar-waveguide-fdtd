# Stage90：Bloch验证阶段最终汇总

日期：2026-09-23

## 结构与计算对象

- 二维AR入耦表面光栅
- 周期：335.5 nm
- 齿宽：167.75 nm
- 占空比：50%
- 齿高：210 nm
- 波导芯层：y=-300到0 nm
- 表面光栅齿：y=0到210 nm
- 目标：638 nm附近TM Bloch导模

## 可作为阶段最终结论

| 指标 | 推荐报告值 | 依据 |
|---|---:|---|
| Bloch共振波长 | 638.1 ± 0.1 nm | 网格、时间、采样点和源位置鲁棒性 |
| 归一化Bloch kx | -0.118613 | 638 nm相位匹配目标点 |
| Q | 约119 ± 0.5 | 时间和采样位置变化范围 |
| 638 nm附近群折射率 | 约1.810 | Stage83局部色散斜率 |
| 芯层+光栅区域 `|E|²`集中度 | 约88-89% | Stage84和Stage86 |
| Bloch预测入射角 | -12.9796° | Stage83色散插值换算 |
| 有限12齿FDTD最佳角 | -13.0358° | Stage79 Accuracy 4 |
| 两类模型角度差 | 0.0562° | Stage85闭环 |
| 局部色散斜率 | -670.173 nm/normalized-k | Stage83线性拟合 |

## 鲁棒性证据

| 检查 | 峰位变化 |
|---|---:|
| 3.5→2.5 nm网格细化 | 0.0258 nm |
| 500→800 fs时间延长 | 0.0085 nm |
| 三个监视器位置 | 0.0121 nm |
| 三个偶极源位置 | 0.0331 nm |

这些变化均远小于1 nm，说明638.2 nm附近的Bloch峰识别可靠。

## 物理解释

1. Stage83的色散线说明归一化kx增大时，共振波长下降。
2. Stage84显示约78%的加权`|E|²`位于波导芯层，约11%位于表面光栅齿高度范围，合计约89%，因此该峰属于与表面光栅相互作用的导模。
3. Stage85把Bloch k换算成自由空间入射角，与有限12齿Gaussian入耦峰仅差0.0562°，完成无限周期本征模与有限器件响应的闭环。
4. Stage88-89表明监视器或激励源位置会改变振幅，但几乎不改变共振频率，符合本征模物理。

## 只能作为辅助指标

- `Q≈119`描述当前无限周期Bloch单元的时间衰减性质，不是有限12齿光栅的耦合效率。
- `|E|²`集中度不是严格总电磁能量占比；严格能量还需介电常数色散和磁场项。
- 群折射率来自当前较窄k范围的线性拟合，只适用于638 nm附近。

## 当前不能下的结论

- 不能由Bloch Q推断AR眼镜最终亮度。
- 不能由单周期模型得到完整入耦效率、出瞳均匀性、FOV、眼盒或鬼像。
- 不能据此宣称RGB共用同一光栅已经解决。
- 不能把2D结果直接当成3D斜入射与锥角响应。

## 推荐工作参数

- 快速粗扫：7.5-10 nm网格，300 fs
- 常规设计：5 nm网格，300-500 fs
- 最终复核：2.5-3.5 nm网格，800 fs

## 下一学习阶段

Bloch相位匹配验证已经足够，不应继续围绕同一个峰无限优化。下一阶段建议转入有限器件性能：

1. 回到12齿有限FDTD模型；
2. 统一定义真正的入耦效率和功率守恒；
3. 分离目标TM导模、反向导模、透射、反射和辐射损失；
4. 建立效率预算表；
5. 再进入齿数、渐变占空比/apodization和带宽优化。
