# Stage210–211：有限宽散射场的固定模式基底验证

## 目的

Stage209b 已把有齿总场精确分成无齿背景、光栅散射场和相干交叉项，但散射场功率 7.692612% 仍同时含导模与辐射。Stage210–211 的任务是把散射复场投影到同一个波导横截面本征模基底，得到真正的目标导模功率。

## 方法校验

- `mode_right` 与 `power_right` 完全同面：x=7 µm、y span=1.1 µm、z span=0.9 µm。
- 从有齿模型计算固定模式场，再把有齿场、插值后的无齿场及其复场差分别传给 `expand`。
- mode1 小试中，`a_scattered = a_patterned - a_reference` 的误差为 `5.55e-16`，b系数误差为 `2.19e-16`。
- 手工固定基底展开与内置 mode expansion 的 mode1 前向功率只差 0.001774 个百分点。
- 因此复场扣除、模式归一化和前后向定义通过验证。

| 指标 | 结果 |

| `neff>1` 导模前向和 | 7.677171% |

| 导模净功率 | 7.676693% |
| TM导模前向和 | 7.671597% |
| TE导模前向和 | 0.005570% |
| 目标TM mode1前向 | 7.479729% |
| 目标mode1后向 | 0.000239% |
| mode1占导模前向功率 | 97.4282% |
| 直接散射净功率减导模净功率 | 0.015918 pp |

主要非目标导模是 mode7（TM，neff=1.141883），前向功率约0.129845%；其次是 mode4（TM，neff=1.479124），约0.062022%。TE导模合计只有约0.00557%，说明该结构的偏振选择性较好。

## 16→32模式收敛

32模式中 `neff>1` 的导模数量仍是10，新增17–32全部属于PML离散的辐射/连续谱近似，不是新增导模。

| 指标 | 16模式 | 32模式 | 变化 |
|---|---:|---:|---:|
| 目标mode1前向 | 7.479729% | 7.480181% | +0.000452 pp |
| 导模前向和 | 7.677171% | 7.677316% | +0.000145 pp |
| 导模净功率 | 7.676693% | 7.676983% | +0.000289 pp |
| TM导模前向和 | 7.671597% | 7.671741% | +0.000144 pp |
| TE导模前向和 | 0.005570% | 0.005571% | +0.000001 pp |
| mode1导模纯度 | 97.4282% | 97.4322% | +0.0040 pp |

- 32模独立基底相对固定16模，前16模逐模最大变化仅0.000452 pp，说明模式相位和排序一致。
- 新增17–32的散射前向功率精确和约0.008138%；不依赖相位的保守上界为0.069661%。
- 新增辐射模式的前/后向净和不单调，这是PML离散连续谱的基底性质；禁止把所有辐射模式简单相加后用“能量闭合最好”选择模态数。
- 工程报告应使用已收敛的导模子空间，辐射余量用直接Poynting功率与导模净功率之差报告。

## 当前可报告结论

在当前0.60 µm有限宽、0.90 µm输出监视器、dz=40 nm的plane-wave方法pilot中：

- 目标TM基模耦合：约 **7.480%**。
- 全部导模净耦合：约 **7.677%**。
- 目标mode1占导模前向功率：约 **97.43%**。
- 该模式投影在16→32模之间已经数值收敛。

这些数值仍不是毫米级AR入耦器的最终效率，因为横向计算域和有限光束尚未做物理收敛。它们的作用是证明背景扣除和目标导模测量链已经正确。

## 下一步

1. 锁定当前固定基底方法，不再增加模式数。
2. 做有限宽z域/输出面收敛，但评价量改为目标mode1，而不是`power_right`。
3. 随后把横向均匀plane wave替换为有明确束腰、焦点和位置的3D Gaussian beam。
4. 横向0.60 µm仍是资源pilot，不代表实际AR眼镜毫米级入耦孔径。
