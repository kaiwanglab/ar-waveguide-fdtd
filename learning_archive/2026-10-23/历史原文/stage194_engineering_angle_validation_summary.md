# Stage194：638 nm 工程角度接受度验证

## 固定条件

- 最终几何保持不变：P=328.75 nm、W=185 nm、H=310 nm、shift=-240 nm、24齿
- 638 nm 独立单色激励，source wavelength span=0
- TM偏振，3.5 nm网格，mode/power报告面 x=7 µm
- 扫描变量只有 `source → angle theta`

## 结果

| 指标 | 数值 |
|---|---:|
| 峰值角度 | -15.1° |
| 峰值 mode1 | 60.6064% |
| 3 dB阈值 | 30.3032% |
| 左3 dB边界 | -18.1043° |
| 右3 dB边界 | -12.6910° |
| 3 dB角度接受宽度 | 5.4133° |

| 峰值到右边界 | 2.4090° |

## 如何理解

3 dB边界表示目标mode1效率下降到峰值一半的位置。当前二维模型在638 nm下的半功率角度窗口约为5.41°。窗口左右不完全对称，符合斜齿、有限齿数与单向耦合结构的非镜像对称特征。

这里得到的是“入射角接受窗口”，不能直接等同于整副AR眼镜最终FOV；完整FOV还受显示光机角谱、波导内传播、扩瞳、出耦和人眼眼盒共同限制。
