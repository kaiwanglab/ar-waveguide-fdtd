# Stage69 三参数联合公差 8 角点验证

## 基准与角点

- 基准结构：period = 335.5 nm，duty = 50%，height = 210 nm
- 基准结果：TMsum = 25.3505%（mesh accuracy 3）
- 联合角点：period = 332/339 nm，duty = 41.5/58.5%，height = 180/240 nm

## 结论

单因素 95% 公差不能直接组合成一个三维矩形制造窗口。8 个角点中只有 Case 3 和 Case 6 严格达到 95%；Case 5 为 94.9578%，接近阈值但仍应视为临界，并通过重复仿真或更高网格精度确认。

最差角点为 Case 8：period = 339 nm，duty = 58.5%，height = 240 nm，TMsum = 19.6665%，保持率 = 77.5782%。

## 2^3 因子效应（对保持率的高水平均值减低水平均值）

| 项目 | 效应（百分点） | 解读 |
|---|---:|---|
| Period | -0.723 | 单独平均主效应较小，但不能忽略其交互作用 |
| Duty | -5.080 | 三个主效应中最大 |
| Height | -2.654 | 次要主效应 |
| Period × Duty | -9.397 | 最强交互项 |
| Period × Height | -0.249 | 本角点范围内较弱 |
| Duty × Height | -4.814 | 明显交互项 |
| Period × Duty × Height | -0.047 | 本角点范围内较弱 |

这些效应只描述当前两个水平之间的 2^3 角点，不证明区间内部完全线性。

## 下一步候选联合窗口

为了给三项偏差共同留出 95% 总保持率，可先让每个单因素边界达到约 `0.95^(1/3) = 98.3%`。根据已有单因素数据，下一轮候选窗口为：

- period = 335.5 ± 2.0 nm，即 333.5/337.5 nm
- duty = 50 ± 5 个百分点，即 45/55%
- height = 210 ± 20 nm，即 190/230 nm

该窗口只是 Stage70 待验证候选值，不是已经确认的制造规格。
