# Stage196：独立单色光谱工程验证

## 方法

- 固定最终几何与入射角 -15.1°。
- 每个波长单独设置 `source wavelength span=0` 并重新运行。
- 每个波长重新更新 mode_right 的4个波导模式。
- 不使用改变宽带源span后读取中心点的方法。

## 结果

| 指标 | 数值 |
|---|---:|
| 峰值波长 | 638 nm |
| 峰值 mode1 | 60.6064% |
| 半功率阈值 | 30.3032% |
| 左3 dB波长边界 | 621.035 nm |
| 右3 dB波长边界 | 648.573 nm |
| 3 dB单色波长带宽 | 27.538 nm |

## 模式连续性

618–658 nm范围内，mode1与mode3的TE fraction均约为0%，保持TM；mode1有效折射率从1.65201平滑变化到1.63771，没有发生模式编号跳变。

## 边界

该带宽描述固定 -15.1°入射下，此638 nm设计的目标TM基模保持峰值一半以上的波长范围。它不能直接解释为RGB共用带宽，也不能代替角度×波长联合响应或完整AR系统FOV验证。
