# Stage 119：周期制造容差验证

日期：2026-09-27  
固定条件：638 nm、入射角 -13.6 deg、名义周期334 nm、占空比62.5%、高度290 nm、顶部偏移-280 nm、模式面x=5 um。

## 目的与判据

本阶段不再寻找最高效率，而是评估制造后周期偏差造成的性能下降。

保持率定义：

`retention = TM(period) / TM(334 nm) * 100%`

采用95%保持率作为当前工程判据。该阈值是设计选择，不是物理定律。

|---:|---:|---:|
| 327 nm | 30.0097% | 90.4031% |
| 328 nm | 31.0727% | 93.6055% |
| 328.5 nm | 31.5337% | 94.9942% |
| 329 nm | 31.9502% | 96.2490% |
| 331 nm | 33.0883% | 99.6774% |
| 334 nm | 33.1954% | 100.0000% |
| 336.5 nm | 31.9052% | 96.1133% |
| 336.8 nm | 31.6815% | 95.4394% |
| 337 nm | 31.5227% | 94.9611% |
| 339 nm | 29.6122% | 89.2059% |

5 nm网格插值得到95%边界约为328.50 nm和336.98 nm。

## 3.5 nm边界复核

名义334 nm效率采用Stage116的33.2128%。

| 周期 | 3.5 nm TM效率 | 保持率 |
|---:|---:|---:|
| 328.5 nm | 31.4903% | 94.8138% |
| 337.0 nm | 31.5570% | 95.0146% |

结合局部斜率，最终估计：

- 95%周期下限：约328.57 nm
- 95%周期上限：约337.01 nm
- 相对名义334 nm：约 -5.43/+3.01 nm
- 理论对称极限：约 +/-3 nm
- 留出数值与生产余量后的推荐暂定规格：+/-2.5 nm

## 物理解释

1. 周期变化会改变光栅动量 `2*pi/period`，从而破坏入射光与波导模的相位匹配。
2. 当前名义点两侧响应不对称，周期增大方向下降更快。
3. 名义点并不一定是制造鲁棒性的中心；后续可以根据制造分布把名义周期略向容差窗口中心移动，但必须同时检查峰值、波长和角度响应。
4. 当前结果是单参数独立扰动；真实制造中的周期、线宽和高度相关性需在后续联合蒙特卡洛中验证。
